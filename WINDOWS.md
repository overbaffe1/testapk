qWDTT для Chrome — Windows x64
==============================

Одноразовая установка:

1. Распакуйте ZIP в обычную папку. Не запускайте файлы прямо из архива.
2. Откройте chrome://extensions и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку
   `qwdtt-windows-x64` — ту, где прямо лежит файл `manifest.json`.
4. Дважды нажмите qwdtt-setup.exe из этой же папки.
5. Дождитесь окна «qWDTT установлен».
6. Полностью закройте все окна Chrome и откройте браузер снова.

У расширения закреплён постоянный ID:
innpafjoibpjdgdemphggiomjlppglgj

Установщик работает только в профиле текущего пользователя:
- файлы: %LOCALAPPDATA%\wdtt-tunnel
- регистрация Chrome: HKCU\Software\Google\Chrome\NativeMessagingHosts
- Program Files, службы Windows и HKLM не используются.

Использование:

1. Откройте qWDTT.
2. Вставьте ссылку подписки.
3. Выберите RAW, WG или SOCKS5.
4. Нажмите «Подключить».
5. После статуса «Подключено» нажмите «Проверить IP».

Режимы:
- SOCKS5 — WireGuard работает в userspace, UAC не требуется.
- WG — системный Wintun + wireguard-go. При подключении подтвердите стандартный запрос UAC.
- RAW — системный Wintun передаёт raw IP через raw-порт подписки. При подключении подтвердите UAC.

Для RAW подписка должна содержать поле raw с портом RAW-сервера.
В режимах WG/SOCKS5 используется стандартный DTLS-порт подписки.
Chrome во всех режимах получает трафик через локальный 127.0.0.1:1080 —
это внутренняя деталь, вручную запускать его не надо.

В WG/RAW qWDTT автоматически создаёт системные маршруты и удаляет их при отключении.
Маршрут к TURN-серверу и указанные split tunnel домены остаются на физическом интерфейсе.
В комплект включён официальный подписанный wintun.dll 0.14.1.

Go, Node.js, PowerShell и командную строку использовать вручную не требуется.
